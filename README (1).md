# ECG Signal Processing and Heart Rate Analysis (MATLAB)

##  Project Objective
This project implements a complete ECG signal processing pipeline using MATLAB.
The objective is to preprocess an ECG signal, detect QRS (R-peaks), and calculate
heart rate from the detected beats.

---

##  Biomedical Relevance
Electrocardiogram (ECG) signals are widely used to monitor cardiac activity.
Accurate detection of R-peaks helps in:
- Heart rate estimation
- Rhythm analysis
- Cardiac health monitoring

---

##  Methodology
1. Synthetic ECG signal generation
2. Noise removal using digital filters
   - High-pass filter for baseline wander removal
   - Low-pass filter for high-frequency noise removal
3. QRS (R-peak) detection using peak detection
4. Heart rate calculation from RR intervals
5. Visualization of results
